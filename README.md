## 仕組み（ステージ2〜3の式）

モデルの中には、色や形などを担当する専門家がいます。ある専門家を1人外して答えがどう変わるかを見れば、誰が実際に何を担当していたかがわかります。ゲートの値は文章の側だけから決まるので、専門家が実際に何を渡したかは反映しません。そこで「外したら何が壊れるか」で役割を判定します。

記号：$Z$ は各専門家の出力をスロットに圧縮して並べた行列、$I_D$ は専門家 $D$ のスロットの集合、$q$ は注目する側、$k_i$・$v_i$ はスロット $i$ のキーとバリューです。

**① 注目の配分**

$$a_i=\frac{e^{s_i}}{\sum_j e^{s_j}},\qquad s_i=\frac{q^\top k_i}{\sqrt d},\qquad \mathrm{out}=\sum_i a_i v_i$$

**② 専門家 $D$ を外す（−∞マスク）**

$$s_i\leftarrow-\infty\quad(i\in I_D)$$

$$a_D=\sum_{i\in I_D}a_i,\qquad a_i^{(-D)}=\frac{a_i}{1-a_D}\quad(i\notin I_D)$$

外した分の注目は、残りのスロットへ同じ比率で配り直されます。スロットをゼロで消すと $s_i=0$、$e^0=1$ となって注目がまだ配られるため、−∞ を使います。

**③ $D$ の寄与（差分）**

$$\mathrm{out}=a_D\,\bar v_D+(1-a_D)\,\mathrm{out}_{-D}$$

$$\Delta_D=\mathrm{out}-\mathrm{out}_{-D}=a_D\,(\bar v_D-\mathrm{out}_{-D})$$

$\bar v_D$ は $D$ のスロットの中身を注目で重み付き平均したものです。差分は「$D$ への注目量」×「$D$ の中身が残りとどれだけ違うか」になります。

**④ 差分ヘッド**

$$h=W_O\,[\,\Delta_1\Vert\,\Delta_2\Vert\cdots\Vert\,\Delta_M\,]$$

$M$ は専門家の数です。各専門家の差分をマルチヘッドのように並べて線形結合します。

**⑤ 出力側での測定**

$$\mathrm{KL}_D(t)=\mathrm{KL}\big(p_t(\cdot\mid Z)\,\Vert\,p_t(\cdot\mid Z_{-D})\big)$$

$p_t$ は答えの $t$ 語目の予測分布、$Z_{-D}$ は $D$ を外した $Z$ です。これを「専門家 × 語の種類（色語・形語など）」の表にし、対角が大きければ役割分担ができていると判定します。KL は下げる損失ではなく、大きいほどその専門家が効いていることを示す測定値です。
