## ファイル構成と使い方

### データ作成
- `generate_factor_dataset_v9_compact.py`
  - 指定したパスにテストデータを生成します。
  - モデル側でそのパスを指定すればそのまま使用できます。

### モデル
- `model/expert_flowx_5experts_v9_compact.py`
  - ステージ0〜ステージ2までの学習を行います。

  | ステージ | 内容           |
  |----------|----------------|
  | ステージ0 | 専門家事前学習 |
  | ステージ1 | 通常学習       |
