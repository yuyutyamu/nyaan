## ファイル構成と使い方
  - ステージ1までは組み合わせ汎化モデルです。
  - ステージ2以降は別ルートで蒸留します。
  - 別ルートに自然な因果介入し、答えの精度を落とさずに内部表現を意味のある形に整えます。

### データ作成
- `generate_factor_dataset_v9_compact.py`
  - 指定したパスにテストデータを生成します。
  - モデル側でそのパスを指定すればそのまま使用できます。
